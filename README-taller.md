# Taller de Arquitectura de Software — Sistema ERP (Módulo de Compras)

Este repositorio contiene la documentación de arquitectura del **Módulo de Compras** de un Sistema ERP, elaborada como parte de un taller práctico de arquitectura de software. El trabajo combina gestión ágil del backlog (épicas, historias de usuario, criterios de aceptación y priorización MoSCoW) con documentación de arquitectura siguiendo la plantilla **arc42** y el modelo de diagramas **C4**.

## Contenido del repositorio

- [`arc42-template-ES.md`](http://./arc42-template-ES.md) — Documento principal de arquitectura: introducción y metas, restricciones, contexto del sistema, vista de bloques, vista de ejecución, conceptos transversales y glosario.  
- [`images/`](http://./images/) — Diagramas generados con PlantUML:  
  - `c1.png` — Diagrama de Contexto (C1)  
  - `plantuml.png` — Diagrama de Contenedores (C2)  
  - `datos.png` — Diagrama de Secuencia (escenario "Registrar un producto nuevo")  
  - `producto.png` — Diagrama Entidad-Relación del módulo de Compras
